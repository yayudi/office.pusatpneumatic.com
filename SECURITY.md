# Security Policy

## Supported Versions

Kami saat ini hanya memberikan _security updates_ untuk versi utama (major/minor) terbaru dari repositori ini.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Kami sangat mengutamakan keamanan sistem DPS-WMHRIS. Jika Anda menemukan kerentanan keamanan (_vulnerability_) pada sistem ini, **tolong JANGAN melaporkannya secara publik melalui GitHub Issues**.

Sebaliknya, kami meminta Anda untuk melaporkannya secara privat melalui email ke:
**<yudhi.indrajaya00@gmail.com>**

Harap sertakan informasi berikut dalam laporan Anda:

- Deskripsi detail dari kerentanan tersebut.
- Langkah-langkah untuk mereproduksi celah keamanan (_Proof of Concept_).
- Dampak potensial dari celah keamanan tersebut.

Tim kami akan mengkaji laporan tersebut dan berusaha memberikan respon awal maksimal dalam waktu 48 jam. Kami tidak akan mempublikasikan detail celah keamanan sebelum perbaikan/patch resmi dirilis.
